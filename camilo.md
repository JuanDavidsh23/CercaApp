# Camilo

## Temas asignados

- **Gestión de dependencias con `pnpm` y monorepositorios**
- **Configuración de variables de entorno y seguridad con `expo-secure-store`**

## Resumen de exposición

Camilo explicará cómo `pnpm` mejora la gestión de paquetes en monorepositorios, reduciendo duplicados y acelerando instalaciones. También mostrará la configuración de variables de entorno en Expo y el uso de `expo-secure-store` para almacenar datos sensibles de forma segura en dispositivos móviles.
